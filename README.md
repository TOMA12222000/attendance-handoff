# 勤怠打刻自動化の再構築要件

GitHub Pagesで配信する公開用の静的ページです。ビルドや外部サービスは不要です。

## 更新

`index.html` の表示文と `id="prompt"` 内の依頼文を編集し、mainブランチへコミット・プッシュします。GitHub Pagesの配信元はmainブランチのルートです。

公開前に機密情報、認証情報、社内URL、既存の業務コードが含まれていないことを確認してください。

## 確認

公開URLをログアウト状態で開き、文章の表示と「全文をコピー」ボタンを確認します。コピーした文章をテキスト欄に貼り付け、全文が一致することを確認します。
